# GitQuickTool 设计与实施计划

> 状态更新（2026-09-13）：用户选择“先直接使用 SourceGit，保留源码方便以后修改”。以下为暂停的原始设计，不是已完成功能声明。空项目骨架已移除，当前交付请阅读 ../README.md 和 SourceGit功能对照.md。

规格来源：../../Docs/Git使用指南.md，以及用户本次完整需求。技术：C#、.NET 8、WPF，无第三方 UI 或 Git 包。

## 功能映射（实现前清单）

| 指南操作 | 命令／流程 | 计划入口 |
| --- | --- | --- |
| 进入项目目录 | Set-Location（非 Git） | 选择文件夹、最近仓库 |
| 本地姓名、邮箱 | config --local user.name / user.email | 设置身份 |
| 状态、确认工作区干净 | status | 文件面板、刷新 |
| 未暂存差异 | diff | 未暂存 Diff |
| 全部暂存 | add . | 全部暂存 |
| 指定文件暂存 | add -- 路径 | 多选暂存，补选相关 .meta |
| 暂存概览 | diff --cached --stat | 暂存概览 |
| 提交工作流 | status → diff → add → diff --cached --stat → commit -m → status | 文件、提交面板 |
| 最近十条历史 | log --oneline --decorate -10 | 历史 |
| 最新提交概览 | show --stat HEAD | 提交详情 |
| 创建并切换分支 | switch -c 新分支 | 分支 |
| 切换分支 | switch 分支 | 分支 |
| 合并工作流 | switch main → merge 功能分支 | 分支（独立两步） |
| 取消暂存 | restore --staged -- 路径 | 文件 |
| 丢弃指定文件修改 | restore --source=HEAD --staged --worktree -- 路径 | 恢复（两次确认） |
| 撤销最新普通提交 | 干净检查 → revert --no-edit HEAD | 恢复 |
| 解决冲突并提交 | status → 人工编辑 → add → commit | 冲突面板 |
| Unity 资源引用 | 资源和 .meta 一起暂存 | 默认配对选项 |
| 排除 Unity 缓存 | 检查 ignore 规则和已跟踪缓存 | Unity 检查 |
| 保存 Unity、关闭编辑器、备份 .git | 人工建议 | 提示及 README |

额外明确需求：单选/多选/全部取消暂存、远程 CRUD、fetch/pull/push/upstream、本地/远程分支列表、指定起点创建分支、安全删除分支、stash push/list/apply/pop/drop、提交详情/复制哈希、已暂存及两个提交的 Diff、冲突打开/暂存/继续/中止、安全确认、中文错误、命令预览、控制台、最近仓库。指南未涉及 reset/clean/rebase/tag/cherry-pick，不增加无规格要求的危险命令。

## 架构

- Core/Models：GitResult、FileChange、RepositorySnapshot、CommitEntry、OperationDefinition。
- Core/Services/GitCommandRunner：唯一 Git 进程边界。ArgumentList 传参、UTF-8 双流异步读取、退出码、超时/取消及整个进程树终止。禁止 shell 拼接，禁用终端交互和 pager，保留凭据管理器授权能力。
- Core/Services/GitService：仓库检测、NUL 分隔的状态解析、暂存与提交验证、只允许预定义操作、冲突及 Unity 检查。字面路径避免 Git pathspec 通配符误选。
- Core/Services/OperationCatalog：集中声明每项操作的字段、学习提示、命令、风险、前置条件。界面和执行共用定义，预览就是实际参数。
- Core/Services/RepositorySettingsStore：LocalAppData/GitQuickTool/settings.json，原子写入，损坏配置可恢复并提示。
- App/ViewModels：仓库快照、选择集合、命令执行串行化、取消、操作结果、日志、表单字段和通知。
- App/Views：仓库栏、文件/分支/远程/历史/Diff/Stash/恢复/设置页签、共享操作表单、文本结果、底部控制台。代码后置仅处理选择和窗口生命周期。
- App/Services：文件夹选择、确认对话框、剪贴板和外部编辑器文件打开；Git 逻辑不进入视图。

危险恢复、stash drop/pop、删除分支/remote、中止操作显示目标仓库、精确命令及影响，默认取消，再次确认。普通写操作也有命令预览。执行期间锁定仓库选择与操作；取消仍刷新状态，不自动重试写操作。切换/合并/revert 要求干净工作区；冲突由用户人工解决，工具仅检测和暂存。
