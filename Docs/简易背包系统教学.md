# Unity 简易背包系统教学

这套背包已经配置到项目中。它只负责收集和展示：按 `E` 打开宝箱获得物品，按 `I` 打开或关闭背包。打开背包不会暂停游戏，停止 Play 后数据会恢复为空。

## 第 1 步：从正确的场景开始

1. 在 Project 窗口打开 `Assets/Scenes/persistent.unity`。
2. 等待 Unity 完成脚本编译。
3. 查看 Console，确认没有红色错误，再点击 Play。

检查结果：游戏应从 persistent 场景进入地图；按 `I` 能显示标题为 `Inventory` 的面板，再按一次关闭。

## 第 2 步：认识背包数据结构

打开 `Assets/代码/Inventory/Core/`：

- `ItemData.cs`：一种物品的配置，包含英文名称和显示颜色。不同的 ItemData 资产就是不同物品。
- `InventoryStack.cs`：一条背包记录，保存物品和数量。
- `Inventory.cs`：保存所有记录，并负责新增或累加数量。
- `AddItemEventSO.cs`：让地图场景中的宝箱把奖励发送给 persistent 场景中的背包。

检查结果：`Inventory.AddItem` 会按 ItemData 资产引用查找已有记录；同一物品再次加入只增加数量，不新增一行。

## 第 3 步：查看自动测试

1. 打开 `Window > General > Test Runner`。
2. 选择 `EditMode`。
3. 点击 `Run All`。

也可以使用菜单 `Tools > Inventory > Run Core Tests`。

检查结果：6 个测试全部通过。核心累加测试会先加入 Ore 2 个，再加入 3 个，最终只有一条记录且数量为 5；无效物品和非正数数量不会改变背包。

## 第 4 步：查看物品和跨场景事件

在 Project 窗口查看：

- `Assets/Data SO/Events/Add Item Event.asset`
- `Assets/Data SO/Inventory/Ore.asset`
- `Assets/Data SO/Inventory/Wood.asset`

选择 persistent 场景中的 `Player`，可以看到 `Inventory` 组件引用了 Add Item Event。Ore 使用灰色色块，Wood 使用棕色色块，没有依赖物品图片。

检查结果：三个资产都存在，Player 的 Inventory 事件引用不为空。

## 第 5 步：查看宝箱配置

打开 `Assets/Scenes/Forest.unity`，在 Hierarchy 中依次选择：

- `Chest1`：Ore × 3
- `Chest2`：Ore × 2
- `Chest3`：Wood × 1

`Assets/代码/general/chest.cs` 会先验证奖励配置。配置有效时，宝箱打开并发送一次奖励，然后禁用交互碰撞体并移除交互标签；配置无效时保持关闭并在 Console 输出警告。

检查结果：同一宝箱重复按 `E` 不会再次增加数量。

## 第 6 步：查看 I 键输入

1. 双击 `Assets/Settings/InputSystem/PlayerInputControl.inputactions`。
2. 展开 `GamePlayer` Action Map。
3. 选择 `ToggleInventory`。

检查结果：Action Type 为 Button，并绑定 `<Keyboard>/i`。`PlayerInputControl.cs` 是由 Unity Input System 自动生成的文件，不要手动修改。

## 第 7 步：认识背包 UI

打开 persistent 场景，在 `Canvas/InventoryPanel` 下可以看到标题、Empty 提示和 Scroll View。Panel 默认处于隐藏状态；列表行预制体位于 `Assets/Prefabs/UI/InventoryItemRow.prefab`。

每一行由一个基础 Image 色块和 TMP 文本组成。例如累计获得 5 个矿石后显示 `Ore x 5`。

检查结果：InventoryPanel 默认隐藏；Content 使用垂直布局并根据内容自动调整高度。

## 第 8 步：理解 UI 刷新方式

`InventoryUI.cs` 挂在 persistent 场景中始终启用的 `UI Manager` 上，而不是挂在会被隐藏的 InventoryPanel 上。

- 按 `I` 打开时立即重建显示内容。
- 背包打开期间获得物品时立即刷新。
- 面板关闭期间只记录数据，不执行无意义的列表刷新。
- 已创建的行会被复用，不会在每次刷新时反复销毁和创建。

检查结果：关闭背包后打开三个宝箱，再按 `I`，应一次显示最终累计结果。

## 最终验收

1. 从 persistent 场景进入 Play，按 `I`，看到 `Empty`。
2. 再按 `I` 关闭面板。
3. 靠近 Chest1 按 `E`，背包显示 `Ore x 3`。
4. 打开 Chest2，仍只有一行，变为 `Ore x 5`。
5. 打开 Chest3，新增 `Wood x 1`。
6. 再次尝试 Chest1，数量不变。
7. 背包打开时观察玩家、敌人或游戏时间，确认游戏仍继续运行。
8. 停止 Play，再次运行时背包为空，这是尚未实现存档的预期结果。

如需重新自动配置或检查场景引用，可使用 `Tools > Inventory > Configure Simple Inventory` 和 `Tools > Inventory > Validate Simple Inventory`。执行前请先保存自己正在编辑的场景。
